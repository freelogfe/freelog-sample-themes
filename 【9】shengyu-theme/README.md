# 声屿 · Shengyu

音乐与播客混合主题，目录为 `【9】shengyu-theme`。采用 Vue 3、Pinia、Vue Router、Vite 和 Freelog Runtime。

## 启动

```powershell
cd 'E:\freelog\freelog-sample-themes\【9】shengyu-theme'
npm install
npm run serve
```

默认端口 **8109**，HTTPS 与其他主题一致。通过 Freelog 节点的 `dev` 参数连接本地主题，页面展示节点真实内容。已移除 `?preview=1` 示例预览。

本机开发暂时通过目录链接复用音乐主题的 `node_modules`；依赖声明和锁文件保留在新主题中，独立检出后正常安装即可。

## 页面与数据
 
跨节点本地联调：节点原主题未配置 `bundleTool=vite` 时，停止占用 8109 的服务后运行 `npm run serve:compat`。
此模式输出普通 IIFE 脚本和完整 CSS，使用 HTTPS 8109 服务，可沿用 `?dev=https://本机IP:8109&theme=%2Fpodcast-list`。
保存源码后自动重新构建，终端提示完成后手动刷新节点页面；此模式不提供 Vite HMR。
兼容产物位于 `dist-compat`，正式构建仍使用 `npm run build` 输出到 `dist`。

- 首页：节点横幅、热门音乐、新碟、歌单、热门播客、最近更新。
- 音乐：歌曲、专辑、歌单分类；分页、排序、详情。
- 播客：连载播客、播客节目、播单；合集子节目详情。
- 搜索：匹配音乐与播客标题、艺人；遍历资源分页。
- 收藏：复用登录与收藏接口，支持音乐／播客筛选。
- 播放：复用音乐主题播放器及授权逻辑；音乐、播客共用播放队列。
- 评论：存在 `ZhuC/Freelog插件-评论插件` 依赖时挂载，并同步深浅模式；未配置时不影响页面。

支持资源类型：`音乐`、`音乐专辑`、`歌单`、`连载播客`、`播客节目`、`播单`。
保留 `detail?id=...&subID=...` 旧链接兼容，同时支持 `itemId`。
收藏与播放记录使用 `shengyu-` 前缀，与原音乐主题分开。

## 外观规范

设计来源：[声屿 Figma](https://www.figma.com/design/6PWgqngkbyvLiCmcWqbltm/声屿)，颜色依据 `201:8649`。

所有新页面使用 `src/assets/css/shengyu.css` 的 `--sy-*` 语义变量，默认暗色，支持直接切换深浅模式和本地记忆。

主题状态绑定在子应用的 `#app` 和 `#music-theme` 根节点上，以兼容 Freelog 的 CSS 隔离；在节点容器内不会修改宿主页面的主题。分享弹窗和传给评论插件的颜色也使用当前子应用的主题。

全局右下角显示外观、使用主题、分享和播放器入口。工具按钮使用 68px 圆形、10px 间距及 30px 边距；小屏幕工具按钮使用 48px。播放器直接使用音乐主题的 `player-v2`，桌面默认显示 78px 折叠入口，空队列显示耳机占位；悬停向左展开返回箭头、上一首、播放／暂停、下一首控制条，离开后收回。点击箭头或封面展开底部完整播放器，点击收起按钮通过位移、缩放及淡出动画回到右下角。不再使用独立头像按钮或“暂无播放内容”弹窗。预览与正式节点共用该组件，预览不请求真实音频。外观按钮单击直接切换深浅模式（暗色显示太阳、浅色显示月亮），不弹出菜单，分享弹窗支持二维码和复制链接。

`options_theme_url` 可配置声屿主题发布后的资源地址；未配置时，“使用声屿主题”进入资源市场搜索声屿。

- `options_homeRecentCount`：首页**音乐-热门推荐**与**播客-最近更新**的展示条数（共用同一数值，默认 10；填正整数）。新碟、歌单、热门节目等模块不受此项影响。

主题和分享入口复用音乐主题的 `home-float-menu`：鼠标悬停或键盘聚焦时向左展开，显示标题、说明和阴影，并随 `theme-light` / `theme-dark` 切换样式。显式配置 `options_entranceShow`（或 `entranceShow`）为“隐藏”时隐藏主题入口。播放后折叠播放器仍使用原组件的悬停控制条。

正式节点配置了 `ZhuC/Freelog插件-主页分享`（或旧名称 `ZhuC/_Freelog插件-主页分享`）时，分享入口打开原主页分享插件，保留名片下载与社交分享操作；未配置或加载失败时使用二维码弹窗，支持复制链接和下载二维码。

歌曲、专辑、歌单和播客的内容分享使用 `ZhuC/Freelog插件-展品分享`，需将该插件添加为主题依赖。主题仅负责挂载、关闭及加载失败重试，不再实现分享正文和社交按钮。分享插件需使用支持“音乐／播客”子集 `itemId` 的版本（本仓库对应 `freelog-sample-widget/【1】share-widget`），否则旧插件分享单集时会丢失子集参数。

| 品牌色 | #8FC914 | #8FC914 |
| 背景 | #111314 | #FFFFFF |

正式页面素材通过 `src/assets/theme.ts` 显式导入，图标位于 `src/assets/design`，默认图片位于 `src/assets/images`；SVG 图标内联加载以避免微前端路径重写。未引用素材不会随 public 目录自动发布。横幅与音乐主题一致，读取节点封面 `nodeInfo.coverImage`，未配置时不显示背景图片；页头 Logo 读取 `nodeInfo.nodeLogo`，未配置时不显示 Logo。

## 代码入口

- `src/views/shengyu/index.vue`：新主题路由页面。
- `src/components/shengyu-card.vue`：音乐、专辑、歌单与播客卡片。
- `src/components/shengyu-search.vue`：搜索历史下拉、键盘选择、单条删除与清空；声屿独立保存最近 10 条记录。
- `src/components/shengyu-floating-tools.vue`：所有路由共享的悬浮工具栏。
- `src/api/shengyu.ts`：混合资源查询、合集分页与授权状态归一化。
- `src/utils/theme-manager.ts`：外观状态。
- `src/components/player-v2.vue`、`src/utils/hooks.js`：继承的播放器与 Freelog 逻辑。

原音乐主题的页面副本暂时保留，新路由使用 `views/shengyu`；这些副本不参与新主题页面渲染。类型检查针对新应用入口和实际依赖，未启用旧副本的全量检查。

## 验证

```powershell
npm run test
npm run typecheck
npm run build
```

搜索支持标题、艺人和所属合集名称，扫描分页及合集子项；搜索和收藏均按歌曲、专辑、歌单、播客四类展示，默认歌曲，不设“全部”。分类使用设计稿的文字色细下划线，空态在内容区居中显示。搜索词保存在 URL，刷新和浏览器前进后退可恢复查询。搜索下拉支持方向键选择、回车提交、Esc 关闭，中文输入法确认候选词不会提前提交。

自动测试覆盖合集分页、子项身份及授权状态、异常空页退出、缺失授权不能视为已授权、预览素材完整性、混合搜索和搜索历史异常存储。

真实节点中的登录、签约授权、音频流、收藏持久化、评论插件和微信分享仍需部署到 Freelog 节点联调；本地设计预览不能验证这些外部行为。详情使用共用模板，评论内容来自插件，推荐区展示同类资源；实际内容和页面高度由节点数据决定。
